# Journey Micro Animations

Pure HTML + CSS keyframe micro animations for the custom WordPress animation block.

Each animation has its own folder with two files named after it:

- `<name>.html`: the markup fragment (inline SVG; any photo is embedded)
- `<name>.css`: its styles and keyframes

Every animation runs on one `--cycle` whose first and last frames are the finished
graphic, so it loops without a jump and play-once / reduced motion end on it.

| Folder | Description |
| --- | --- |
| `deploy-product-customer/` | Customer on a call, connected to AI, IVR/IVA, Live Agent, Payments, eSignatures, Passkeys, eForms and OTP |
