# Journey Micro Animations

Lightweight HTML + CSS keyframe micro animations (Slack-homepage style).

Each animation lives in its own folder with an independent `index.html` and `style.css`
(plus any photo it needs). Graphics are inline SVG; type is Inter.

| Folder | Description |
| --- | --- |
| `deploy-product-customer/` | Customer on a call, connected to AI, IVR/IVA, Live Agent, Payments, eSignatures, Passkeys, eForms and OTP |

Animations scale with their container (max 1200px wide) and respect `prefers-reduced-motion`.
